버전 1.0.1.0 — 첫 정식 출시

2026년 11월 3일 · Microsoft Store · 무료 · x64

ZinniaShark Note 1.0.1.0은 무료로 제공합니다. 대한민국 Microsoft Store에서 설치할 수 있습니다.

  • Microsoft Store에 처음 공개한 무료 Windows 문서 작성 앱입니다.
  • 글·이미지·오디오·비디오를 .adq 문서에 함께 저장합니다.
  • 서식 편집, 표·목록·인용·코드 블록, 목차와 여러 문서 탭을 제공합니다.
  • 문서 암호 설정과 이 PC에서의 로컬 작업 이어하기를 제공합니다.

Microsoft Store에서 다운로드 · 설치·시작 가이드

무료 1.0의 기능 범위

본문·제목·문자 및 문단 서식, 표·목록, 이미지·링크·오디오·비디오, 목차·찾기·바꾸기, 여러 문서 탭, ADQ 저장·열기, 문서 암호, 로컬 작업 이어하기와 편집 환경 설정을 제공합니다.

2.0 Free/Pro는 향후 계획입니다. 고급 변환·문서 비교·장기 버전 관리·30일 Pro 평가는 현재 제공하지 않습니다.

지원 환경과 알려진 제한

현재 Store 패키지는 Windows x64 PC용입니다. Store에 등록된 최소 OS는 Windows 10 빌드 19045.0 이상이며 Windows 11에서도 사용할 수 있습니다. 편집 화면에는 WebView2 Evergreen Runtime이 필요합니다. ARM64·x86 전용 패키지, macOS·모바일·웹 편집기는 제공하지 않습니다.

  • .adq 중 ADQ2 컨테이너·논리 v3를 지원합니다. Word·한글·PDF·Markdown 가져오기·내보내기는 제공하지 않습니다.
  • 저장은 동기화되지 않는 로컬 고정 NTFS 폴더를 사용합니다.
  • 작업 이어하기는 PC·Windows 사용자 간 동기화와 독립 백업을 제공하지 않습니다.
  • 실제 탭 전환 및 앱 재시작 시 실행 취소 기록이 초기화됩니다.
  • 미디어 재생은 지원 형식·코덱·파일 상태와 실행 환경에 영향을 받습니다.

업데이트와 지원 안내

Microsoft Store에서 업데이트를 확인할 수 있습니다. 업데이트 전 열린 문서와 미저장 작업을 외부 .adq 파일로 저장하고 별도 사본을 보관하세요. 제거·초기화하면 내부 작업·설정이 삭제될 수 있습니다.

지원 종료는 기존 사용권 종료와 구분합니다. 지원 수명주기·주요 버전 업그레이드 정책은 현재 검토 초안이며, 실제 시행 조건은 문서별 상태를 확인하세요.
