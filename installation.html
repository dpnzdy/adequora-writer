INSTALL & START

처음 실행하기 전에.

설치 조건을 확인하고, 문서를 안전한 위치에 저장하세요.

1. 설치 경로와 지원 환경

Adequora Writer 1.0.1.0은 무료로 제공합니다. 대한민국 Microsoft Store에서 설치할 수 있습니다. 공식 설치 경로는 다운로드 안내에서 확인하세요.

현재 Store 패키지는 Windows x64 PC용입니다. Store에 등록된 최소 OS는 Windows 10 빌드 19045.0 이상이며 Windows 11에서도 사용할 수 있습니다. 편집 화면에는 WebView2 Evergreen Runtime이 필요합니다. ARM64·x86 전용 패키지, macOS·모바일·웹 편집기는 제공하지 않습니다. Windows 실행 가능 여부와 운영체제 자체의 보안 지원 상태는 구분해서 확인하세요.

Microsoft Store에서 설치하기

  1. 공식 Store 제품 페이지에서 앱 이름 Adequora Writer와 게시자 ZINNIASHARK를 확인합니다.
  2. 무료 받기·설치 버튼을 선택하고 Store의 설치 안내를 따릅니다.
  3. 설치가 끝나면 시작 메뉴에서 Adequora Writer를 실행합니다.
  4. 새 문서를 만들고 Ctrl+S로 로컬 .adq 파일을 저장해보세요.

공개 패키지 버전 1.0.1.0 · 2026년 11월 3일 배포. 설치·업데이트에는 Store의 네트워크·계정 조건이 적용될 수 있습니다.

2. WebView2 Evergreen Runtime

Microsoft Edge 브라우저와 WebView2 Runtime은 별도 구성요소입니다. 편집 화면 실행에는 Runtime이 필요합니다.

  1. 앱에서 Runtime 누락 안내가 나오거나 편집 화면이 열리지 않으면 작업을 저장한 뒤 앱을 종료합니다.
  2. Microsoft 공식 WebView2 다운로드 페이지에서 Evergreen Runtime을 선택합니다. 온라인 설치에는 Bootstrapper, 오프라인 설치에는 x64 Standalone Installer를 사용할 수 있습니다.
  3. 설치가 끝나면 앱을 다시 실행합니다. 회사 관리 PC는 조직의 설치 정책을 확인하세요.
  4. 문제가 계속되면 오류 메시지·앱 버전·Windows 버전을 지원 채널에 알려주세요.

앱을 먼저 제거하거나 초기화하지 마세요. 내부 작업 데이터가 삭제될 수 있습니다.

3. 저장 폴더 선택

동기화되지 않는 로컬 고정 NTFS 드라이브의 일반 폴더를 사용하세요. 예를 들어 내 PC의 고정 C: 드라이브가 NTFS이고 동기화 대상이 아니라면, 쓰기 권한이 있는 개인 작업 폴더를 선택할 수 있습니다.

문서·바탕 화면 폴더도 OneDrive에 연결되어 있을 수 있으므로 실제 경로를 확인하세요. OneDrive 등 동기화 폴더, 네트워크 공유, USB 등 이동식 저장소는 현재 앱에서 저장 대상으로 지원하지 않습니다. 파일 탐색기의 드라이브 속성에서 파일 시스템을 확인할 수 있습니다.

설치 폴더나 관리자 권한이 필요한 시스템 폴더에 문서를 저장하지 마세요. 다른 저장소로 백업하려면 먼저 지원 폴더에 저장하고 파일을 닫은 뒤 파일 탐색기에서 사본을 복사하세요.

4. 첫 문서 만들기

  1. 새 문서를 만들고 본문을 입력합니다.
  2. 제목 스타일을 적용하고 목차에서 이동해 봅니다.
  3. Ctrl+S로 지원 폴더에 .adq 파일을 저장합니다.
  4. 문서를 닫고 Ctrl+O로 다시 열어 내용을 확인합니다.

이미지·오디오·비디오 사용법은 사용 가이드를 확인하세요.

5. 업데이트·제거 전

열린 문서와 미저장 작업을 필요한 외부 .adq 파일로 저장하고 별도 백업한 뒤 앱을 종료하세요. Store판의 업데이트는 Microsoft Store에서 확인합니다.

작업 이어하기는 이 PC의 현재 Windows 사용자 안에서 동작합니다. 제거·초기화하면 내부 작업 데이터가 사라질 수 있으며, 재설치로 되돌아온다고 보장하지 않습니다. 외부 문서 사본을 확인한 뒤 진행하세요.

주요 버전이 바뀔 때는 지원·업그레이드 정책 초안과 해당 버전의 변경 안내를 먼저 확인합니다.
