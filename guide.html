A LITTLE GUIDE TO GET STARTED

첫 문장부터,
차근차근 함께.

문서를 만들고, 자료를 더하고, 다음 작업을 이어가는 방법을 알아보세요.

필요한 안내를 바로 찾으세요

설치·시작 가이드

지원 환경, WebView2와 저장 폴더를 확인합니다.

문제 해결

실행·저장·문서 열기·미디어 문제를 순서대로 살펴봅니다.

버전 소식과 알려진 제한

공개 상태와 업데이트 전 확인 사항을 안내합니다.

사용 가이드

도움이 필요하신가요?
01 / GET STARTED

나의 첫 문서 만들기

작은 문장 하나면 충분합니다. 자료와 설명을 담을 문서부터 시작하세요.

  1. 01

    새 문서를 만드세요

    앱을 실행한 뒤 새 문서를 만들고, 기록하고 싶은 주제와 첫 문장을 적어보세요.

  2. 02

    제목으로 큰 흐름을 잡으세요

    문단 스타일에서 제목을 선택하세요. 제목은 목차에 표시되어 문서 안을 이동하는 길잡이가 됩니다.

  3. 03

    나의 파일로 저장하세요

    Ctrl + S로 저장하고 이름과 위치를 정하세요. 로컬 고정 NTFS 드라이브의 일반 폴더를 사용하세요.

먼저 샘플 문서로 감을 잡아보세요.
02 / WRITE & ORGANIZE

읽고 고치기 좋은 구조 만들기

제목 1~6으로 내용을 나누고, 표와 목록, 인용, 코드 블록으로 자료의 성격에 맞게 정리하세요. 중요한 단어에는 굵게·기울임·밑줄·글자색을 사용할 수 있습니다.

제목과 목차제목을 선택해 필요한 곳으로 이동합니다.
표와 목록비교할 내용과 작업 순서를 정리합니다.
서식과 블록인용·코드·글자 서식으로 흐름을 만듭니다.
찾기·바꾸기반복되는 표현을 찾아 고칩니다.

실제 탭 전환 후에는 이전 탭의 실행 취소 기록이 초기화되며, 앱을 재시작해도 실행 취소 기록은 새로 시작합니다.

03 / ADD YOUR MATERIALS

자료와 설명을 함께 담기

삽입 기능으로 미디어를 넣거나 탐색기에서 지원 파일을 문서로 끌어 넣으세요. 삽입한 자료는 .adq 파일 안에 포함됩니다.

이미지PNG · JPEG · GIF

크기·정렬·회전·뒤집기를 조절하고 설명을 더하세요. 화면 표시 조정과 원본 자산은 구분됩니다.

오디오MP3

문서 안에서 재생하며 중요한 표현과 다시 확인할 지점을 기록하세요.

비디오MP4

장면을 살펴보고 관찰한 점과 떠오른 생각을 본문에 적어두세요.

지원 형식이어도 실제 코덱·파일 상태와 재생 환경에 따라 동작이 달라질 수 있습니다. 음성 인식·자동 녹음·영상 편집 기능은 제공하지 않습니다.

04 / SAVE & CONTINUE

저장과 작업 이어하기 이해하기

파일에 남기는 일과 다음에 이어 쓰는 일은 서로 다릅니다.

파일 저장

Ctrl + S

지금의 변경을 원본 .adq 파일에 반영합니다. 다른 이름으로 저장하면 별도 사본을 만들 수 있습니다.

작업 이어하기

주기적 보존 + 정상 종료 시 보존

이 PC의 현재 Windows 사용자에서 이전 문서와 미저장 작업을 다음 실행에 이어서 편집하도록 돕습니다.

강제 종료·전원 장애에서는 마지막 보존 이후의 입력이 남지 않을 수 있습니다. 작업 이어하기는 별도 백업을 대신하지 않습니다. 중요한 문서는 별도로 백업하세요. 제거·초기화 전에 미저장 작업도 외부 ADQ 파일로 저장하십시오.

이렇게 체험해보세요

  1. 먼저 문서를 저장합니다.
  2. 문장을 한 줄 더 쓰고 앱을 정상 종료합니다.
  3. 다시 실행해 이전 작업이 이어지는지 확인합니다.
  4. 이어 쓴 내용을 파일에 반영하려면 다시 저장합니다.

정상적인 보존 데이터와 사용 가능한 저장 공간이 필요합니다. 다른 PC나 Windows 사용자 사이에서 자동으로 동기화되지는 않습니다.

05 / PROTECT YOUR DOCUMENT

필요한 문서에 비밀번호 설정하기

문서별로 비밀번호를 설정·변경·해제할 수 있습니다. 암호화된 문서는 제목줄과 탭의 자물쇠 표시로 저장 상태를 확인하세요.

문서 내용과 포함 자산을 함께 암호화합니다.

ADQ2 암호화에는 Argon2id 키 유도와 AES-256-GCM을 사용합니다. 암호 문서는 다음 실행에서 이어서 열 때에도 비밀번호를 다시 확인합니다.

처음이라면 연습용 사본에서 비밀번호 설정과 다시 열기를 체험하세요. 비밀번호를 잊으면 작업 보존본만으로 암호를 해제할 수 없으므로 안전하게 보관해주세요.

06 / FIND YOUR FLOW

나에게 맞는 작업 환경

  • 툴바에 자주 쓰는 도구를 표시하고 순서를 조절하세요.
  • 익숙한 작업에 맞춰 단축키를 지정하세요.
  • 문서 표시 너비와 목차 너비를 조절하세요.
  • 목차 경계를 드래그해 읽기 좋은 공간을 만드세요.
