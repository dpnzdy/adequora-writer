FREQUENTLY ASKED QUESTIONS

자주 묻는 질문

01어떤 Windows 환경에서 사용할 수 있나요?

현재 Store 패키지는 Windows x64 PC용입니다. Store에 등록된 최소 OS는 Windows 10 빌드 19045.0 이상이며 Windows 11에서도 사용할 수 있습니다. 편집 화면에는 WebView2 Evergreen Runtime이 필요합니다. ARM64·x86 전용 패키지, macOS·모바일·웹 편집기는 제공하지 않습니다.

02앱은 어디에서 다운로드하나요?

Microsoft Store에 게시되어 대한민국 Store에서 무료로 설치할 수 있습니다. 홈페이지와 다운로드 페이지의 공식 Store 버튼을 이용하세요. 설치 조건과 첫 실행 방법은 설치·시작 가이드에서 확인할 수 있습니다.

다운로드·설치 안내 보기
03무료인가요? 출시 정보가 궁금해요.

현재 공개 버전 1.0.2.0은 무료이며, 2026년 11월 3일 Microsoft Store에 처음 공개했습니다. 앱 계정 등록과 유료 라이선스 없이 사용할 수 있습니다. 2.0 Free/Pro는 향후 계획이며 현재 판매하지 않습니다.

04인터넷 연결 없이 문서를 작성할 수 있나요?

클라우드 업로드를 전제로 하지 않는 로컬 파일 중심 앱입니다. 문서는 내 PC의 파일로 열고 편집·저장합니다. Store 설치·업데이트 등 배포 서비스의 이용에는 네트워크가 필요할 수 있습니다.

05Word·한글·PDF 파일도 열거나 저장할 수 있나요?

현재 지원하는 문서 형식은 ADQ2/논리 v3의 .adq 파일입니다. DOCX·HWP/HWPX·PDF·Markdown 가져오기·내보내기는 현재 지원 범위에 포함되지 않습니다.

06이미지·오디오·영상은 문서와 함께 저장되나요?

PNG·JPEG·GIF 이미지, MP3 오디오, MP4 비디오를 삽입할 수 있습니다. 삽입한 미디어는 .adq 파일 안에 포함됩니다. 다른 PC에서는 호환되는 ZinniaShark Note와 해당 미디어를 재생할 수 있는 환경이 필요합니다.

07작업 이어하기와 파일 저장은 어떻게 다른가요?

Ctrl+S는 변경 내용을 원본 .adq 파일에 반영합니다. 작업 이어하기는 작업을 주기적으로, 그리고 정상 종료 시 보존해 다음 실행에서 편집을 이어가도록 돕습니다. 이 PC의 현재 Windows 사용자에 적용되며, 강제 종료·전원 장애에서는 마지막 보존 이후 입력이 남지 않을 수 있습니다.

08다른 기기에서도 작업을 이어갈 수 있나요?

현재의 작업 이어하기는 이 PC·현재 Windows 사용자에서 동작합니다. 클라우드 동기화나 다른 기기 간 자동 이어하기는 제공하지 않습니다. 파일을 다른 PC로 옮겨 열려면 호환되는 앱이 필요합니다.

09문서 비밀번호를 잊었어요. 어떻게 하나요?

문서 내용과 포함 자산을 비밀번호로 암호화합니다. 비밀번호를 잊으면 작업 보존본만으로 암호를 해제할 수 없습니다. 문서에 설정한 비밀번호를 안전하게 보관해주세요.

10문서 용량이나 열린 문서 수에 제한이 있나요?

문서·자산 크기, 열린 문서 수와 메모리·표시 자원에 한도가 적용됩니다. 파일 크기만으로 열기 가능 여부를 판단할 수 없으며, 같은 크기의 모든 문서에서 동일한 성능을 보장하지 않습니다. 용량 제한 안내가 나오면 작업을 저장하고 불필요한 탭을 닫은 뒤 안내 내용을 확인해주세요.

11미디어가 재생되지 않으면 어떻게 하나요?

지원 형식과 문서·자산의 용량을 확인하고, 원본 파일이 Windows에서 정상적으로 재생되는지 살펴보세요. 문제가 계속되면 앱 버전, Windows 버전, 파일 형식과 오류 메시지를 이메일로 알려주세요.

12탭을 바꾸거나 앱을 재시작한 뒤 실행 취소가 되지 않아요.

현재 앱은 실제 탭 전환에 성공하면 이전 탭의 Undo/Redo 기록을 초기화합니다. 앱을 재시작할 때도 실행 취소 기록은 새로 시작합니다. 중요한 변경 전에는 사본을 저장해두세요.
