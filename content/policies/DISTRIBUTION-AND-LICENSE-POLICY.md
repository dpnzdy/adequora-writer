## 4. 30일 평가

사용자가 ‘30일 Pro 무료 평가 시작’을 선택하고 시작 확인이 완료된 시각부터 연속 30일간 평가합니다. 설치·첫 실행·업데이트만으로 평가를 시작하지 않습니다. 평가 기간 중 앱을 사용하지 않아도 시간은 경과합니다. 종료 시각을 앱에서 확인할 수 있게 제공합니다.

- 사용자 1명당 주요 버전별 1회이며 재설치로 기간을 초기화하지 않습니다.
- 결제 정보를 요구하지 않고 자동 결제·자동 구매하지 않습니다.
- 평가 기간 중 구매하면 문서·설정을 유지한 채 Pro로 전환합니다.
- 시작·만료 확인에 사용하는 데이터와 네트워크 요구는 시작 전에 안내합니다.
- 인증 오류를 평가 종료로 위장하지 않고, 원인과 재시도 방법을 구분해 안내합니다.

### 평가 종료 시 문서 처리

| 대상 | 종료 후 동작 |
|---|---|
| 앱 실행·기본 편집 | Free로 계속 사용 |
| 기존 ADQ 문서 | 열기·기본 편집·저장 유지 |
| 비교·변환 등 Pro 명령 | 새 실행을 제한하고 구매 또는 취소 선택 제공 |
| 이미 생성한 결과 파일 | 삭제·워터마크 삽입·권한 회수 없음 |
| 문서에 저장된 결과·서식·자산 | 유료 권한 부재를 이유로 삭제·축소하지 않음 |
| 저장·내보내기 진행 중 만료 | 이미 승인한 단일 작업은 완료하도록 처리하고 다음 실행부터 제한 |

문서 열기·저장·기본 복구를 구매 화면으로 가로막지 않습니다. Pro 전용 문서 요소를 향후 도입한다면 Free에서 표시·보존하는 규칙을 먼저 마련해야 합니다. 문서 내용을 유지하지 못하는 구현은 출시하지 않습니다.

## 5. Pro 사용권과 재설치

개인 1명당 본인 전용 PC 최대 2대에서 사용하며, 조직은 실제 사용자별 좌석을 구매합니다. 여러 사람의 계정·키 공유는 허용하지 않습니다. 직접 판매 라이선스의 PC 교체는 이전 장치의 사용을 중단한 후 새 장치에서 활성화하는 방식으로 지원하고, 장치 고장으로 해제가 불가능하면 구매 증빙으로 지원을 요청할 수 있게 합니다.

스토어 구매 복원은 해당 구매 계정과 스토어가 제공하는 절차를 이용합니다. 판매 채널 간 자동 권한 이전은 별도 안내가 없는 한 제공하지 않습니다. 직접 판매의 키·파일 방식과 스토어 권한 확인 방식은 출시 전에 확정합니다.

활성화 후에는 상시 온라인 재인증을 요구하지 않습니다. 인증 서비스 종료 시에는 종료 전에 영구 라이선스 파일 또는 동등한 오프라인 권한 유지 수단을 제공합니다. 이 약속을 지원할 인증 구현을 판매 전에 준비합니다.
